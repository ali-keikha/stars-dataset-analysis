#  Stars Dataset Analysis

A collection of exploratory data analysis (EDA) notebooks on a star dataset using **Python**, **Pandas**, and **NumPy**.

The goal of this project is to explore different characteristics of stars by answering a series of research questions and analyzing relationships between astronomical features.

##  Analyses

### 1. Dataset Overview

* Dataset structure
* Missing values
* Duplicate records
* Feature information
* Basic descriptive statistics

### 2. Color vs Temperature

* Explore the relationship between star color and temperature
* Identify inconsistent color labels
* Standardize color names before analysis

### 3. Absolute Magnitude Analysis

Research question:

> What percentage of stars have an absolute magnitude between 1 and 10? What are the most common spectral class and star type within this group?

### 4. M-Class Stars Profile

Research question:

> What are the main characteristics of M-class stars in this dataset?

The notebook analyzes:

* Color distribution
* Average temperature
* Average luminosity
* Average radius
* Maximum and minimum values
* Star type distribution

### 5. Radius vs Temperature

Research question:

> Is there a correlation between a star's radius and its temperature?
